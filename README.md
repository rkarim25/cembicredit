# CEMBI CEEMEA Master Credit Database Platform (cembicredit)

An institutional, deterministic credit intelligence platform and master financial database covering 52+ Emerging Markets corporate and banking issuers across CEEMEA, GCC, and Africa.

## Core Capabilities
- **Master Database (database/):** Versatile JSON documents storing 7-year multi-period financials (2021A-2027E), balance sheets, debt maturity profiles, and industry-specific metrics (RERA escrow cash, NIM, NPL, CAR, ARPU).
- **Embedded Qualitative Intelligence:** Granular analyst notes, broker consensus (Arqaam, Citi, J.P. Morgan), and filing footnotes attached to every data inflection point.
- **Standalone 7-Year Excel Models (models/*.xlsx):** Formatted workbooks with native Excel cell comments and forensic recovery waterfalls.
- **Real-Time Zero-AI Web Portal (index.html, 	rends.html):** Sub-millisecond peer matrix screening, multi-factor filtering, and time series trend plotting with zero AI latency or hallucinations.
- **Bi-Directional Notion Sync (scripts/sync_notion.py):** Live synchronization with the Notion Research Repository and Comp Sheets Hub.
- **Cognitive Credit & Broker Ingestion (scripts/ingest_source.py):** Drop-folder parser for incoming sell-side research and Cognitive Credit exports.
